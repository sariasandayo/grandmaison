# ありあわせのグランメゾン

バイト初日、高級レストランでまさかのワンオペ！？
ガラポンから出てきた「ありあわせ」の食材だけで、5皿のフルコースを仕立てるスマホ向けブラウザゲームです。

どんな組み合わせでも料理として成立し、もっともらしい名前が付きます。

## あそびかた

1. **本日のお題を確認**：ジャンル（フレンチ／イタリアン／中華／和食）と季節、来店する3人のお客さまが決まります。
2. **食材を開放**：食材の入った容器はゆっくり回り続けます。ボタンを押している間だけ排出口が開き、食材が出てきます。離したらその皿の取得は終わりです（1皿につき1回）。
   - 容器の中の食材をタップすると、狙いの印を付けられます。
3. **調理法を選ぶ**：出てきた食材は全部その皿に使います（フードロス反対！）。食材ごとに「焼く」「煮る」「ソースにする」などの調理法を選ぶと、料理名と皿の中の役割が決まります。
4. **お出しする**：皿ごとにお客さまが反応します。5皿出したら「本日の評価」です。

## 特徴

- 食材 300種類、調理法 20種類、定番料理 500品
- ジャンルごとに変わるコースの構成と、調理法の呼び名（例：焼く → ロースト／グリリア／炒め／焼き）
- 好みの違う9人のお客さま。それぞれの口調で評価します
- 定番料理がそろうと料理名が変わり、評価も上がります。作った料理はレシピ帳に記録されます
- 見た目はすべてドット絵（食材・盛り付け・ガラポン・お客さまの顔）
- ホーム画面に追加でき、一度開けばオフラインでも遊べます（PWA）

## 動作環境

- スマートフォンのブラウザ（縦画面）を想定しています。PCのブラウザでも遊べます
- 最近の Safari／Chrome／Edge など、一般的なブラウザで動きます

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | ゲーム本体（データ・ドット絵・処理・スタイルをすべて含む） |
| `manifest.webmanifest` | ホーム画面に追加するための設定 |
| `sw.js` | オフラインで遊ぶためのサービスワーカー |
| `icon-192.png` / `icon-512.png` | アプリのアイコン |
| `icon-maskable-192.png` / `icon-maskable-512.png` | Android の丸型などで切り抜かれる用のアイコン |
| `apple-touch-icon.png` | iPhone のホーム画面用アイコン |
| `favicon-32.png` / `favicon-64.png` | ブラウザのタブ用アイコン |

ビルドや外部ライブラリは不要です。すべてのファイルを同じ階層に置き、静的に配信するだけで動きます。

## 公開のしかた（GitHub Pages）

1. 上のファイルをすべてリポジトリの直下に置きます。
2. リポジトリの **Settings → Pages** で、公開元に `main` ブランチの `/ (root)` を選びます。
3. 表示された URL をスマートフォンで開き、共有メニューから「ホーム画面に追加」します。

更新したときは、`sw.js` の `VERSION` を変えると、古いキャッシュが自動で消えて新しい版に切り替わります。
